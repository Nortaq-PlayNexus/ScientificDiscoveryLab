## 3. The Most Important Methodological Correction

The single most consequential correction was recognising a **phase-randomisation /
propagation conflation** in the project's early statistics (date: 2026-09-16,
inside the audit framework).

**The error.** The original "phase randomization" statistic compared two
intensity distributions:

```
I(x)   = |ASM(u)|²              (original field, propagated)
I_rand = |ASM(|u|·e^{iφ_rand})|²   (same amplitude, randomised cell phases, propagated)
```

The mean absolute difference was reported as ~0.13. This was interpreted as
evidence that "phase was information." That interpretation was wrong.

**Why it is wrong.** Let `A(x) = |u(x)|`. Then:

```
|A·e^{iφ}|² = A²                     (same-plane identity, exact)
```

The cell-wise **intensity** is unchanged by a random phase factor, exactly as
textbook Fourier optics predicts. After propagation, `ASM(A·e^{iφ_rand})` has a
different relative phase relationship than `ASM(A)`, so the propagated fields are
*not* expected to be identical — and they are not. The 0.13 difference is the
natural result of **propagating a phase-incoherent field vs a phase-coherent
field** using a linear unitary operator. It is not "phase information" and it is
not an AI-generated discovery.

**Quantitative evidence (verified):**

| Measurement | Value | Source |
|---|---|---|
| Same-plane intensity difference (cell-wise) | max relative difference ≤ 6.55e-16 | `FINAL_PHASE_REPORT.md` |
| Same-plane identity confirmed | exact | theory |
| After 160 µm propagation, NCC between I and I_rand | 0.0564 | `FINAL_PHASE_REPORT.md` |
| After 160 µm propagation, vortex count (original) | 74 | `FINAL_PHASE_REPORT.md` |
| After 160 µm propagation, vortex count (phase-randomised) | 21,738 | `FINAL_PHASE_REPORT.md` |

This conflation explains a large fraction of the early "positive" findings.
Correcting it was the first and most important methodological correction in
this project.

## 6. Strongest Results

These are the most defensible positive results. Each was obtained with
deterministic, reproducible tools, each was cross-checked by an independent
implementation or an independent auditor, and each is compatible with known
linear Fourier optics.

**R1 — The 32 µm structure is real, periodic, and INHERITED (not generated).**
The "32.0 µm" in the field is built into the generator lattice (column pitch
32.0 µm). The "emergence-vs-inheritance" control
proved the 32 µm pattern in the output is **inherited** from the input — it is
*not* an emergent structure spontaneously produced by propagation. This is the
correct explanation of the original observation and the core result.

**R2 — The +24/−24 topological charge balance is real and conserved.**
The generator contains 8×6 = 48 unit-charge vortices on alternating checkerboard
signs: +24 and −24, net charge = 0. After propagation the raw classification
initially counted "+24 / −24" asymmetries, but the independence re-analysis
(48 cores) reproduced the balance and confirmed net charge conservation. This is
exactly what scalar optics requires (topological charge of a field is
conserved).

**R3 — Propagation physics is unitary and independent-code reproducible.**
ASM unitarity ~10⁻¹³, energy error ~3×10⁻¹⁶, an independent numpy ASM gives
NCC = 1.000000 with |ΔI| ≤ 1.9e-13.

**R4 — Vortex-density statistics match theory in the lab.**
Lab `EXP-0003`: vortex density (Kac-Rice / Nye-Berry) reproduced, with
n_meas/n_pred = 0.9952 … 1.0011, and a shift-invariant counting method that
fails gracefully only near Nyquist (~17 – 24%). This is the strongest
hard-physics quantitative anchor in the whole project.

**R5 — The forbidden-statistics constraint yields a clean null.**
Percolation/forbidden-region runs (`EXP-0005/6/7`) produced a clean null
(bond_wrap p_c = 0.500687 ± 0.0317, χ² 4.738 → 2.239), supporting H0. This
negative is itself a result: it rules out one class of "spontaneous structure"
claims in the project.

**R6 — Methodology is now reproducible and independently verified.**
6/6 independent-check PASS (Section 4.6). A full 12-test validator battery is
documented; the audit framework itself is now a repeatable asset.
