## Promotion rule

A row can move above **INCONCLUSIVE** only if the effect is reproduced across
independent seeds, grid refinement, padding, subpixel shifts, detector
definitions, null models, and an independently written implementation. A
surviving result still requires expert/laboratory review before any Level 4 or
Level 5 language.
